# One-Liner Marathon

make.fun bounty entry for [One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2).

The program writes one one-line comedy joke to `/output/entry.txt`.

## Run

```sh
npx tsx main.ts
```

or with Node 22 and a TypeScript runner of your choice, with `MAKEFUN_OUTPUT_DIR` set to the output directory.

## Entry

> I bought a standing desk, and now I stand all day resenting a piece of furniture that has never once stood up for me.
